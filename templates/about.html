Algorithmic Architecture & Methodology

How StockPulse AI Predicts the Future

Our multi-tier forecasting pipeline reconciles classical econometric models with modern deep recurrent neural networks to generate robust multi-day price targets.

1. Long Short-Term Memory (LSTM)

Implemented using TensorFlow & Keras 3 with a 4-layer architecture of 50 recurrent memory cells per layer coupled with Dropout (0.10) to mitigate overfitting. The model reads sequences across a 7-day timestep window to preserve temporal memory gradients across volatile swings.

2. ARIMA (6, 1, 0) Model

Powered by Statsmodels, ARIMA differences non-stationary historical series by parameter d=1, calculates autoregressive parameters p=6, and fits moving average residuals q=0 to capture linear persistence and seasonal mean reversion.

3. Multi-Step Linear Regression

Trained on standardized features via Scikit-Learn StandardScaler. Maps continuous price momentum into an analytical 7-day trajectory vector to calculate expected trajectory bounds and calculate root-mean-square errors against actual closes.

Recommendation Engine Logic

The system aggregates the tomorrow forecast across all three algorithms and calculates the trajectory mean. If current closing price is below the forecasted mean and social/market sentiment polarity is positive, the system issues a BUY (RISE) signal. If price is above forecast mean or sentiment is negative, a SELL (FALL) recommendation is triggered.

BUY Trigger Rules

Current Close < Forecast Mean AND Sentiment Polarity > 0 indicates undervaluation and upward momentum.

SELL Trigger Rules

Current Close ≥ Forecast Mean OR Sentiment Polarity ≤ 0 indicates peak price exhaustion and downward pullback.
